An image restoration project using a U-Net-based deblurring model. The Kaggle Dogs vs. Cats dataset is repurposed by applying Gaussian blur to clean images, creating paired training and evaluation data.

### What I worked on

Built a controlled deblurring workflow covering data preparation, model training, and evaluation on synthetically blurred natural images.

### Code

The public repository includes dataset loading, model, loss, metric, training, and test code. The documented environment uses Python and PyTorch.
